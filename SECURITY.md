# Política de seguridad y divulgación responsable

## Reportar una vulnerabilidad

**No abra un issue público.** Use la función de reporte privado de vulnerabilidades del repositorio (pestaña *Security → Report a vulnerability*) cuando esté habilitada [pendiente: P-05], o contacte de forma privada a los mantenedores listados en `GOVERNANCE.md`.

Incluya: versión afectada, descripción, pasos de reproducción con **datos sintéticos**, impacto estimado y, si la tiene, una propuesta de corrección.

## Proceso

1. Acuse de recibo.
2. Evaluación de severidad y alcance.
3. Corrección en rama privada y publicación de una versión firmada.
4. Aviso de seguridad público coordinado con quien reportó, con crédito si lo desea.

Los plazos de respuesta se publicarán cuando el proyecto cuente con al menos dos mantenedores (P-03); hoy no se comprometen plazos que no se puedan cumplir.

## Alcance

- Código de este repositorio y artefactos publicados (imágenes, paquetes offline, catálogo normativo).
- Fuera de alcance: instalaciones operadas por terceros (repórtelas a su operador), y pruebas sobre sistemas que no le pertenecen.

## Versiones soportadas

Última versión menor publicada (ver `docs/fase-0/14-gobernanza.md`). Aún no hay versiones publicadas.

## Puerto seguro

No se emprenderán acciones contra investigadores que actúen de buena fe, usen solo instalaciones propias o de prueba, no accedan a datos de terceros y sigan esta política.
