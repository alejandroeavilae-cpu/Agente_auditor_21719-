# Política de soporte

**Decisión D-28.** Se da soporte de seguridad a la **última versión menor publicada**. Las correcciones se publican como versiones de parche.

| Situación | Compromiso actual |
|---|---|
| Reportes de vulnerabilidad | Proceso de `SECURITY.md`. No se comprometen plazos de respuesta mientras exista un solo mantenedor (P-03). |
| Errores funcionales | Issues públicos (con datos sintéticos). Sin plazos garantizados. |
| Instalaciones de terceros | El proyecto no opera instancias: cada organización es responsable de su instalación, actualización y respaldo. |
| Versiones antiguas | Sin soporte; se recomienda actualizar verificando firmas. |

Esta política se ampliará cuando haya más mantenedores. El soporte del proyecto es comunitario y gratuito; no existe soporte pagado del proyecto (principio 1.1).
